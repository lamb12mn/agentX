# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Coding Guidelines

### Think Before Acting
- State assumptions clearly. Ask if uncertain.
- Present multiple interpretations, don't silently choose one.
- Speak up if there's a simpler approach.

### Simplicity First
- Solve with minimum code.
- Don't abstract single-use code.
- Don't add unrequested "flexibility".
- If 50 lines solve it, don't write 200.

### Precise Editing
- Only touch what's necessary.
- Don't "improve" adjacent code.
- Match existing style.
- Clean up orphans from your changes.

### Goal-Driven Execution
- Define success criteria before starting.
- Verify progress against criteria.
- For multi-step tasks, briefly outline the plan first.
