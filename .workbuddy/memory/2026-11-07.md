## 参照火山方舟 PromptPilot 补齐本地评测闭环（AgentX）

- 参考页：`https://docs.volcengine.com/docs/ark/promptpilot-overview?lang=zh`。核心机制 = 版本绑定评测集 → 种子样本 → 批量构建评测数据集 → 聚焦低分样本反向修正 → 新版本对比。项目原有 5 个评测工具只到「汇总」，闭环断在这里。
- 本轮新增 3 个纯本地 MCP 工具（零新依赖、不调外部模型）：`add_evaluation_samples`（种子模板 + 变量集单事务批量构建）、`list_evaluation_samples`（低分/未评分/GSB 过滤）、`compare_evaluation_sets`（同资产同模式的平均分差、GSB 净胜率、覆盖率差、`improved`）。实现在 `store/evaluations.ts` + `tools/evaluations.ts`；`index.ts` 展开注册，无需改动。

## 第 2 轮迭代：改写建议 + CLI 评测入口（AgentX）
